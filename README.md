# WorkTimePro

WorkTimePro is a workforce time-tracking system built with C# and ASP.NET Core.

## Overview

The application allows employees to track their working time and breaks, while administrators can monitor work sessions and calculate working hours and earnings.

## Features

* Employee authentication
* Work session tracking
* Start, pause, and resume work sessions
* Break management
* Weekly working-hours tracking
* Administrative monitoring
* Earnings calculation based on hourly wage
* Database persistence
* REST API architecture

## Technologies

* C#
* ASP.NET Core
* Entity Framework Core
* SQL / SQLite
* REST API
* JavaScript
* HTML
* CSS
* Git / GitHub

## Project Structure

The project is organized into separate areas for controllers, data access, models, application configuration, and web assets.

## Purpose

This project was developed as a practical software engineering project to demonstrate backend development, API design, database integration, authentication, and application architecture.
